# SBS brand inputs (read-only)

Inputs for the UX/brand research of SBS Staffing — **not** a decision.

- `logos/` — SBS logo (dark and light variants, from sbsfirm.org). The wordmark is a high-contrast Didone serif with a condensed sans tagline and a red horse/ribbon mark.
- `sbsfirm-reference-analysis.md` — what sbsfirm.org looks like (ink `#050703`, red `#E4042C`, beige `#F3F0EA`, Arial/Helvetica, 0 px radius, no motion).
- `sbs360-design-system.md` — the design system chosen for the sibling product SBS 360° (SBS-derived, red used sparingly).

The staffing product must feel **related to SBS but not identical to SBS 360°**. The research decides how (inherit, adapt, or sibling sub-brand) and must write the rationale.
